401Sessão expirada no meio da saídaqualquer rota autenticada

Sua sessão expirou

Entre de novo para registrar a saída. O que você digitou continua aqui.

Token ausente ou vencido: o middleware devolve 401 sem corpo. Login com senha errada também é 401 (InvalidCredentialsException). Entrar de novo abre o login num Dialog e volta para cá, sem perder o campo.

404Código lido sem ticketGET /access/tickets/by-code/{code}

Nenhum ticket com esse código

Leia o QR de novo. Se o ticket estiver danificado, busque pela placa.

API: "No ticket was found for this code." Pela placa, POST /access/tickets/open-by-plate devolve 404 com "No open ticket was found for this plate.": aí a tela diz "Nenhum ticket aberto para TST0A00" e oferece Registrar entrada.

409Entrada de placa que já está no pátioPOST /access/tickets

TST1B23 já tem um ticket aberto

Registre a saída desse ticket antes de uma nova entrada.

API: "This vehicle already has an open ticket." A resposta não traz o ticket. "Abrir ticket aberto" chama POST /access/tickets/open-by-plate com a placa no corpo.

422Ticket já finalizadoPOST /access/tickets/by-code/{code}/exit

Este ticket já foi finalizado

A saída já foi registrada, talvez em outro terminal. Não precisa fazer mais nada.

API: "Ticket is already closed." É 422, não 409: mesmo quando duas saídas correm juntas, o conflito vira esta resposta.

422Placa em formato inválido na entradaPOST /access/tickets

API: "Invalid plate format." (DomainException → 422). O campo não é apagado. Validar o formato também no front evita a ida ao servidor.

422Saída por placa sem motivoPOST /access/tickets/by-plate/{plate}/exit

Erro:Escreva o motivo da saída sem ticket

API: "The reason is required for an exit by plate." e, acima do limite, "The reason must have at most 500 characters.". A API devolve um erro por vez: com vários campos, só o front consegue listar todos de uma vez no resumo.

Como a API responde

401 credenciais ou token · 403 permissão · 404 não encontrado · 409 conflito (ConflictException) · 422 regra de domínio (DomainException) · 500 "An unexpected error occurred". Corpo: { status, error }. 401 e 403 vindos do middleware de autenticação chegam sem corpo.
