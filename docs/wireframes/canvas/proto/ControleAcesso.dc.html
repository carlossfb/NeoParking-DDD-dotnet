Rotas e componentes

GET /access/tickets?status=&entryFrom=&entryTo=&page=&pageSize= · qualquer operador · lista e abas (Open, Closed).

Conflito com a regra 5 GET /access/tickets?plate= existe, mas põe a placa na URL. Para tickets abertos, usar POST /access/tickets/open-by-plate (placa no corpo). Para todos os status: rota nova necessária.

POST /access/tickets · qualquer operador · "Registrar entrada".

POST /access/tickets/by-code/{code}/exit · qualquer operador · saída pelo código lido no QR.

POST /access/tickets/by-plate/{plate}/exit · qualquer operador · ticket perdido: motivo obrigatório no corpo, autor vem do token. Conflito com a regra 5 a placa vai no caminho.
